# MUSICINATE

Браузерный многодорожечный редактор музыки и звуковых эффектов. Откройте `index.html` в современном браузере. Сборка и установка зависимостей не нужны.

- Импортируйте аудио через кнопку или перетащите файлы в область импорта. Поддерживаемые форматы зависят от браузера.
- Щёлкните по шкале, чтобы поставить курсор. Перетаскивайте клипы по времени или разделяйте их в позиции курсора.
- Выберите клип и настройте обрезку, громкость, панораму, затухание и эффект в инспекторе.
- Нажмите «Экспорт WAV», чтобы скачать стереомикс (PCM, 16 бит).

Аудио обрабатывается локально. Проект хранится в памяти вкладки и сбрасывается при её перезагрузке.
